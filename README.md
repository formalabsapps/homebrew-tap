# FSwitcher for Homebrew

[FSwitcher](https://fswitcher.app) is a ⌘⇥ replacement for macOS, built for working across several displays, Spaces and full-screen apps.

```sh
brew install formalabsapps/tap/fswitcher
```

FSwitcher keeps itself up to date, so `brew upgrade` leaves it alone. `brew uninstall --zap fswitcher` removes it along with its settings.

Requires macOS 26 or later.
